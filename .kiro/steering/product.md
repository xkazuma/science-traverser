# プロダクト概要

クライアントサイドで PDF を描画・閲覧する Vue 製 Web アプリケーション。PDF ファイルは
サーバーへアップロードせず、ブラウザ内（PDF.js / `pdfjs-dist`）で完結して描画する。

将来的には単なるビューアにとどまらず、PDF 上にマーカ・メモを保存し、軽量なレイアウト解析
（docling / paddleocr 相当）で検出した領域をオーバーレイ表示し、レイアウトをグラフ構造として
管理できる「拡張可能な PDF 解析プラットフォーム」を目指す。

## Core Capabilities

- **クライアントサイド PDF 描画**: ローカル PDF を選択／ドラッグ&ドロップで開き、ブラウザ内で
  描画する（アップロード不要）。
- **連続スクロール閲覧**: ページ送り・ズーム・フィット、テキスト選択、アウトライン／サムネイル
  ナビゲーション。大規模 PDF 向けの仮想化。
- **オーバーレイ基盤**: 描画キャンバスの上に、PDF ビューポート座標で位置決めされた拡張レイヤを
  常に備える（フェーズ1では空だが配線済み）。

## Target Use Cases

- 機密性の高い文書をアップロードせずブラウザ内だけで閲覧したいケース。
- 将来的に文書へ注釈（マーカ・メモ）を付与し、レイアウト領域や構造を解析・可視化したいケース。

## Value Proposition

- **プライバシー**: PDF はクライアント内で完結し外部送信しない。
- **拡張性**: 描画ループを自前で所有し、座標系を制御することで、注釈・領域・グラフといった将来
  機能をデータ移行なしに段階的に追加できる。

## 開発フェーズ

- **フェーズ1（現在）**: フロントエンドのみの PDF ビューア。
- **将来構想（フェーズ1の設計で阻害しない）**: マーカ／メモ保存、レイアウト解析の領域描画、
  レイアウトのグラフ構造管理。
